# 双模型与 Skills 工作台

真实功能需要显式启用账号模式并登录。匿名本机兼容入口继续沿用 `LLM_MODEL`，GitHub Pages 为独立模拟，不连接模型、账号、索引或 MCP。

## 模型

输入框提供 DeepSeek V4-Flash／DeepSeek V4-Pro 两项，共用 `OPENAI_BASE_URL` 和 `OPENAI_API_KEY`。服务端映射为 `LLM_FLASH_MODEL=deepseek-flash`、`LLM_PRO_MODEL=deepseek-v4-pro`，部署前须核对当前 Provider 的可用模型目录；目录配置存在不代表远端调用已经可用。密钥不会下发浏览器。

本轮选择贯通 RAG 改写与生成、Agent JSON/native 规划与最终回答、摘要及嵌套知识库调用。模型在运行开始时固定，不修改共享客户端。生成期间禁止切换；已有会话切换先以 revision 保存，回包丢失则核对，无法确认时锁定发送并要求从目录重开。失败不会自动切到另一个模型或 Ollama。

继续历史会话时，规划阶段将已完成问答作为上下文数据传入，最终回答仍保留原对话角色；普通回答不会被当作合法规划。Agent 规划及最终回答的累计输入预算按 token 估算加 10% 余量，与输出上限同单位；扣下一轮规划输入前先检查规划与完整收尾的合计费用，执行工具前为有界结果及完整最终回答留空间。已有工具观察且仅够收尾时，停止后续规划或新工具，用已有结果回答并说明限制，不扣跳过的规划费用；无观察或收尾本身不足则拒绝。默认12000总额、512规划和4096最终上限均未调大。

当前模型未配置时禁止发送；会话空闲且状态已确认时，仍可主动选择另一个可用模型。保存成功后下一轮才使用新选择，不自动降级。

选择优先级是显式本轮参数、会话最近选择、可映射的最近实际模型、账号默认值、Flash。`/workspace/preferences` 可条件更新账号默认；首版界面仅提供会话选择。回答和历史显示回答当时的实际模型；未调用模型的确定性拒答不冒充模型结果。

## 技能管理

侧栏 Skills 打开 `/settings/skills`，支持列表、详情、开关、上传与确认删除。唯一内置 `skill-creator` 默认关闭且不可删除；它的开关只解锁独立的“整理为技能”动作，不注入普通聊天。自定义启用技能只作用于后续 Agent 请求，不作用于 RAG；在途请求保留开始时的技能版本快照，停用或删除不改写历史。

技能只是任务指令，不授予工具或文件权限，不能覆盖系统安全规则。工具仍经过后端 Registry 的 Policy、Schema、审批、审计、去重和预算。

自定义文件是 UTF-8 单文件 Markdown（可带 BOM），最多 64 KiB，格式如下：

```markdown
---
schema_version: 1
name: concise-writing
description: 帮助精简表达
---
先给结论，再给必要依据。
```

元数据只能包含这三个字段，版本必须是整数 1；名称由小写字母、数字、连字符组成，1–64 字符，保留 `skill-creator`。简介 1–200 字符，正文非空且最多 8000 字符，不支持 YAML tag、锚点、别名或重复键。每账号最多 32 个自定义技能，启用正文合计最多 2048 token。新上传默认关闭；相同名称和规范化内容重试返回原记录，内容冲突返回 409。技能内容只向当前账号开放，不放 URL 或 localStorage。

## 整理为技能

先启用 creator，再导入 TXT、MD、文字型 PDF 或 DOCX。文件最多 10 MiB；PDF 最多 200 页，提取文字最多 200000 字符／2 MiB，全部输入必须能放入本轮上下文，放不下要求拆分，不静默截断。200 页是解析保护上限，不能当作 200 页全文模型处理承诺。没有 OCR，不支持扫描件、图片、脚本或外部资源执行。

解析在专用子进程完成，30 秒上限，全局最多 2 个、每账号最多 1 个；取消/超时会终止该 worker。转换只使用 creator 指令和原始资料，不混入自定义技能。模型输出还须通过与上传相同的格式校验和完整性检查；失败、取消、超时或缺少终态均不产生成功产物。

草稿仅在当前页面内存，可预览、下载，只有点击“上传此技能（新项默认关闭）”才保存，不自动安装或启用。重复上传同名同内容技能保留原有启用状态，页面按返回状态提示。离开页面、刷新会丢弃草稿并取消请求。转换使用浏览器生成的操作 ID，服务端只保留去重墓碑，不存原始输入和生成草稿；24 小时保留、每账号最多 128 个操作，重复 ID 拒绝重放。

账号模式启动仅做 additive schema 初始化，不删除旧表、匿名历史或索引。实际默认数据库迁移、备份与公网部署仍需独立授权；本单元验证使用隔离合成库。新增接口为 `/workspace/models`、`/workspace/preferences`、`/skills`、`/skills/{id}`、`/skills/creator/stream`，均验证账号归属且返回 `no-store`，写操作验证 Origin/CSRF。
